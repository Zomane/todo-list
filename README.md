# Todo-list 

Адаптивный список задач на HTML, CSS и JavaScript. В нём можно создавать задачи, отмечать их выполненными, возвращать в активные и удалять. Фильтры дают возможность переключаться между всеми, активными и выполненными задачами. Счётчик показывает общий прогресс.

## Запуск

Откройте `index.html` в браузере. Для запуска через локальный HTTP-сервер, если установлен Python, выполните из папки проекта:

```sh
python -m http.server 8000
```

Затем откройте <http://localhost:8000>. Установка зависимостей и сборка не требуются.

## Хранение задач

JavaScript сохраняет список в localStorage после каждого изменения и загружает его при открытии страницы. При очистке данных сайта задачи удаляются. Если браузер блокирует запись, интерфейс предупреждает о возможной потере изменений после перезагрузки.

Кнопки с солнцем и луной переключают светлую и тёмную темы. Выбор темы сохраняется в браузере через localStorage.
